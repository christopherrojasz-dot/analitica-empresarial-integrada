# Analítica Empresarial Integrada

Repositorio académico del curso de **Analítica Empresarial Integrada – TECSUP 2026-II**.

## 📌 Descripción

Este repositorio está destinado a almacenar y organizar todos los trabajos realizados durante el curso de **Analítica Empresarial Integrada**.

Aquí se irán subiendo progresivamente los archivos desarrollados a lo largo de todas las semanas del curso, incluyendo laboratorios, notebooks, ejercicios, análisis y actividades realizadas en clase.

El objetivo es mantener un registro ordenado de todo el trabajo desarrollado durante el ciclo y contar con una evidencia de los diferentes análisis realizados.

## 📂 Contenido del repositorio

El repositorio se irá actualizando conforme avance el curso y podrá contener:

* Notebooks de Google Colab o Jupyter Notebook (`.ipynb`)
* Laboratorios dirigidos
* Ejercicios desarrollados en clase
* Actividades semanales
* Análisis de casos empresariales
* Archivos de datos utilizados en los laboratorios
* Resultados y evidencias de los trabajos realizados

## 📁 Organización

Los archivos se organizarán por semanas y/o laboratorios para facilitar su ubicación.

## 🛠️ Herramientas

Durante el curso se utilizarán principalmente:

* Python

* GitHub

Mantener de manera organizada todos los trabajos, laboratorios y actividades desarrolladas durante el curso de **Analítica Empresarial Integrada**, permitiendo llevar un seguimiento de los trabajos realizados a lo largo del ciclo.
